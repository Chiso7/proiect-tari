# Proiect: comparatie intre tari

Proiect de portofoliu: unde merita deschis un birou (costuri, salarii, taxe, talent, scenarii de curs valutar).

## Structura

- `data/raw/` - datele exact cum le-ai descarcat; nu le modifici de mana
- `data/processed/` - datele curatate de codul tau
- `notebooks/` - explorare si incercari (fisiere .ipynb)
- `src/` - codul care ramane (fisiere .py)
- `tests/` - teste automate (mai tarziu)
- `requirements.txt` - lista de librarii a proiectului
- `JURNAL.md` - ce ai facut in fiecare zi

## Pornire

1. Deschide folderul in VS Code (File > Open Folder).
2. Mediul virtual `.venv` se activeaza singur in terminalul din VS Code.
3. Librarii noi: le adaugi in `requirements.txt`, apoi rulezi `python -m pip install -r requirements.txt`.
