# Antrenament

Aici scrii exercitiile zilei, inainte sa le lipesti in aplicatia de training.

- Un fisier pe zi, cu numele zilei din aplicatie: `w1d3.py`, `w1d4.py` si asa mai departe.
- Scrii si rulezi aici pana crezi ca e corect. Inainte de fiecare rulare, spune ce rezultat astepti.
- Apoi lipesti codul in aplicatie si apesi "Ruleaza testele".
- Tot aici reproduci in cateva randuri o eroare la care te-ai blocat.
